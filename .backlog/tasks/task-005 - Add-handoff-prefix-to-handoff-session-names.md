## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

## Why

Make handoff sessions immediately identifiable in Pi and Herdr while retaining the descriptive name generated by the shared pi-rename logic.

## Scope

- Prefix the final handoff session and Herdr label with `[handoff] `.
- Keep the unprefixed generated slug for the temporary handoff artifact filename.
- Preserve compatibility with `@tifan/pi-rename` and the chezmoi-managed Herdr tab spinner.
- An explicit `/rename` may intentionally replace the complete name and remove the marker.

## Cold-start context

`packages/pi-handoff/src/index.ts` calls `generateRename`, then passes the resulting name to the handoff path builder, Herdr `--label`, Herdr Pi `--name`, and non-Herdr `appendSessionInfo`. `packages/pi-rename/src/index.ts` only renames a Herdr target automatically when its label is default or temporary, so it should not overwrite the new custom handoff label at startup. The tab spinner at `/Users/tifan/.local/share/chezmoi/dot_local/share/herdr-plugins/tab-spinner` captures the current label, adds frames such as `◐ ` or `⏸ `, and restores the base label when idle.

## Out of scope

Do not change the spinner plugin or make `/rename` preserve a handoff marker after an explicit rename command.
